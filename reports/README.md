# Weekly reports

Reports follow the revised plan's weekly milestones. Each includes at least 300 words of reflection and is ready to paste into Canvas. The reports connect completed tasks to lessons learned, challenges, plan adjustments and next steps. Week 5 brings these elements into one continuous account, with code and measured results inside the narrative.

| [Week 3](week03_report.txt) | Mathematical exercises, upstream tests and related-work audit complete |
| [Week 4](week04_report.txt) | Technical plan and benchmark package prepared for joint review |
| [Week 5](week05_report.md) ([plain text](week05_report.txt)) | Shared residue analysis, mapped substitutions and a verified direct sampling run |
